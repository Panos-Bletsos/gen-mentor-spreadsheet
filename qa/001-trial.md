How do I subtract two numbers?

## Response
In a spreadsheet, subtract by starting with = and using a minus sign.

Pattern: =first_cell-second_cell

For your sheet, think about Planned Hours minus Total Logged in the same row.

So in the first task row:

click the first cell under Remaining Hours
type a formula that starts with =
then select the Planned Hours cell in that row
type -
then select the Total Logged cell in that row
press Enter
